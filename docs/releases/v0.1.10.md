# Vareliox 0.1.10 — Chat, Code and media in one workspace

## Español

- Interfaz unificada: barra lateral redimensionable, compositor que crece con el texto y explorador de proyectos mejorado.
- Imágenes y vídeos directamente desde `+` en Chat y Code, con selección independiente del modelo de conversación.
- Corregidos los modelos multimedia que no aparecían y las herramientas bloqueadas con el texto vacío o sin modelo de chat.
- Descarga integrada de Stable Diffusion 1.5 Q4 y AnimateDiff v3 con su motor privado, sin instalar ComfyUI por separado.
- Biblioteca de modelos instalados con eliminación confirmada y protección de archivos compartidos.
- Progreso, cancelación, reintento, descarga y guardado multimedia en proyectos autorizados.
- Botón Detener rojo, mensajes sin recortar, cierre del menú `+` al pulsar fuera y menú de permisos coherente.
- Migraciones que conservan conversaciones, proyectos, proveedores y credenciales; archivos multimedia referenciados desde el historial.

**Descargas:** instalador Windows x64 `.exe`, Linux x86_64 `.deb` y `.AppImage`. Comprueba los archivos con `SHA256SUMS.txt`. Esta actualización no contiene un nuevo instalador de macOS.

**Pruebas y límites:** se han realizado pruebas reales de imagen, vídeo y cancelación locales en Linux, además de pruebas de interfaz en WebKitGTK. Las pruebas de interfaz de nube usan respuestas simuladas; no certifican acceso ni cuota de tu API. Los procesos de compilación ejecutan pruebas frontend y backend en Windows y Linux; eso no sustituye una revisión visual de Windows. La generación local es experimental: AnimateDiff crea clips cortos sin audio, Windows utiliza un motor CPU y Linux un motor Vulkan para Ubuntu 24.04 x86_64, con bibliotecas y controladores compatibles. Los modelos LM Studio de varios archivos deben eliminarse desde LM Studio. Los instaladores no tienen firma de certificado comercial.

## English

- Unified resizable sidebar, auto-growing composer, and improved project explorer.
- Image and video tools inside Chat and Code, independent of the conversation model.
- Fixed missing media models and tools disabled by an empty prompt or missing chat model.
- Managed Stable Diffusion 1.5 Q4 and AnimateDiff v3 downloads with a private runtime, without a separate ComfyUI installation.
- Installed-model management with explicit deletion confirmation and shared-weight protection.
- Generation progress, cancellation, retry, downloads, and authorized project saves.
- Red Stop control, unclipped user messages, outside-click dismissal, and consistent permission menus.
- Data-preserving settings/history migrations and media file references instead of full base64 history entries.

**Downloads:** Windows x64 installer, Linux x86_64 Debian package and AppImage, with `SHA256SUMS.txt`. No new macOS installer is included.

**Verification and limitations:** real local image/video/cancellation tests and WebKitGTK UI checks were performed on Linux. Cloud UI tests use mocked responses, not live API entitlement checks. Build pipelines run frontend/backend tests on Windows and Linux; Windows visual behavior has not been manually verified. Local diffusion remains experimental: short silent AnimateDiff clips, a CPU engine on Windows, and an Ubuntu 24.04 Vulkan x86_64 engine on compatible Linux systems. Multi-file LM Studio models must be removed in LM Studio itself. Installers are not certificate-signed.
