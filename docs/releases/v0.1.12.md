# Vareliox 0.1.12 — Code summaries stay visible

## Español

- Corregido el resumen o análisis de un proyecto en modo Code que desaparecía al terminar y dejaba el chat cargando: las peticiones informativas ya no se confunden con órdenes para editar archivos.
- Los reintentos de formato conservan la respuesta anterior mientras esperan, también cuando hay error, timeout o cancelación.
- Una reparación válida que solo devuelve JSON conserva la explicación original y sigue respetando la aprobación de operaciones.
- Las operaciones parciales de un reintento fallido no se aplican. Las preguntas siguientes siguen funcionando.
- «Continúa» toma como referencia la última petición relevante, sin reactivar una edición antigua después de un resumen.
- Empaquetado aislado de las capturas antiguas del repositorio: solo los tres instaladores y sus sumas SHA-256 se incluyen como descargas.

Descargas: Windows x64 `.exe`, Linux x86_64 `.deb` y `.AppImage`, con `SHA256SUMS.txt`. Esta versión conserva los datos y configuraciones existentes.

Verificación: pruebas automatizadas frontend/backend en ejecutores nativos Windows y Linux, y nueve comprobaciones de interfaz WebKitGTK en Linux. La regresión usa la interfaz real con respuestas de IA simuladas; no es una prueba de acceso a una API de pago. No se ha hecho revisión visual manual en Windows ni generado un instalador nuevo para macOS. Los instaladores no tienen firma de certificado comercial.

## English

- Fixed Code project summaries disappearing after completion and restarting a loading state: informational requests no longer trigger file-action format repairs.
- Repairs preserve the previous answer while waiting and on errors, timeouts or cancellation.
- Valid JSON-only repairs retain the original explanation and still require the configured operation approval.
- Partial actions from failed repairs are not applied; subsequent questions remain usable.
- Continuations use the latest relevant request instead of reviving unrelated older edits.
- Release downloads are isolated from repository screenshots and checked for the three versioned installer names.

Downloads: Windows x64 installer, Linux x86_64 Debian package and AppImage, plus `SHA256SUMS.txt`. Existing user data and settings are preserved.

Verification: automated frontend/backend tests on native Windows/Linux runners and nine Linux WebKitGTK UI checks. The regression exercises production UI with mocked AI responses, not paid API access. Windows visual behavior has not been manually reviewed; no new macOS installer is included. Installers are not certificate-signed.
